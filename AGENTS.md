## AI Filesystem Organizer skills

### Safe Filesystem Consolidation and Reorganization

For scan-only analysis, consolidation planning, or recovery of a stable filesystem collection, use `.agents/skills/filesystem-organizer/SKILL.md`. The Selected Backup Root must remain quiescent; active-folder organization and generic file cleanup are excluded.

For user-led Custom Layout planning, review, visualization, or output-structure decisions for a materializable Consolidation Plan, use `.agents/skills/consolidation-plan-dialogue/SKILL.md` together with the filesystem-organizer skill.

### Issue tracker and domain

Repository and product development work is tracked in this repository's GitHub
Issues. For those changes, use the canonical domain vocabulary in `CONTEXT.md`
and open an issue before substantial changes. Ordinary filesystem-organizer
scans, Plans, Layout Revisions, and materialization are user workflows and not
repository development work. Do not create or update an issue for them unless
the user explicitly requests issue tracking.

### Python toolchain

For dependency changes, environment synchronization, and quality commands, follow
the `uv` workflow in `README.md#development`.
